# グリッドレイアウト

## アプリ専用ウィンドウで起動・終了

`start-app.cmd` をダブルクリックすると、Edgeのアプリ専用ウィンドウで開きます。右上の「×」は画像・編集履歴・一時データを消去してウィンドウを閉じます。通常のブラウザータブで開いた場合は、ブラウザーの制限で自動終了できないことがあり、その場合は終了案内を表示します。Ctrl+Wでタブを閉じてください。about:blankへは移動しません。

この修正版はペイントを参考にした画面構成です。上部の「ファイル・編集・表示」メニュー、モードタブ、用途別リボン、中央のキャンバス、写真合成の右側の写真一覧で操作します。画像処理・高解像度保存・起動時設定の機能は引き継いでいます。詳しくは `REVISION.md` を参照してください。画面と主要操作のテストは `node verify-paint.cjs`。

自動的に全画面で起動するには `start-app.cmd` をダブルクリックしてください。右上の「□／❐」で標準表示と全画面表示を切り替えます。写真の操作リボンは左側の縦配置、写真一覧は右側、中央の編集領域はメニュー直下から表示します。`index.html` を直接開いた場合はブラウザーの制限により「全画面表示で開始」のクリックが必要です。

「ファイル」の設定から、両モードの起動時の行・列、比率、向き、背景色と、写真合成の配置方法を設定できます。「設定を保存」でこのブラウザーに記録し、次回起動時から反映します。現在の編集内容は変更しません。「初期設定に戻す」を押して保存すると、グリッド分割は横2・縦1・赤・4:3縦向き、写真合成はグリッド・横1・縦2・白・4:3縦向きに戻ります。専用ウィンドウはこのフォルダーの `.desktop-profile` にブラウザー設定を保存します。

グリッド分割の「読み込んだ写真を削除」で現在の写真とタイルプレビューを外せます。「元に戻す」で削除を取り消せます。保存されるのは初期設定のみで、写真や編集履歴は保存しません。

編集領域の上の「元に戻す」で直前の操作を取り消せます。履歴は最大30操作です。画像追加・削除、位置・大きさ・回転・ぼかし・固定、比率・背景色・重なり順などを戻せます。保存済みのファイルは取り消しません。

右上の「終了」は読み込んだ画像、編集履歴、タイル、プレビュー、保存用の一時データを解放してウィンドウを閉じます。ブラウザーが自動終了を許可しない場合は、終了案内を表示します。ディスクへ保存した画像は削除しません。

保存設定のサイズ欄には、各縮小率での画素数と、選択したPNG/JPG形式で実際に生成したファイル容量を表示します。複数画像では1枚目の容量と全画像の合計を表示します。形式を変更すると再計算します。計算中は保存ボタンが一時的に無効になります。MB/KBは1MB=1,000,000バイト、1KB=1,000バイトで表示します。

モード名は「グリッド分割」「写真合成」です。比率は両モード共通で、自由、1:1、3:2、4:3、4:5、16:9、16:10、21:9、1:1.414（A/B判）、1:1.427（L判）、1:1.402（2L判）、数値を入力から選べます。選択枠の右のボタンで縦向き・横向きを切り替えます。

「自由」はグリッド分割では元画像と行・列の数から各タイルの比率を初期設定し、写真合成では最初に追加した写真の比率を初期設定します。表示される幅・高さは自由に編集できます。「数値を入力」でも幅・高さを小数で入力できます。比率の幅÷高さは0.02〜50の範囲です。保存時の画素数は整数に丸めるため、小数比率では最大1画素程度の丸めが生じます。

PCブラウザー向けの写真分割・自由配置アプリです。画像や作業データを外部に送信しません。通信先も外部ライブラリーもありません。

## 起動

このフォルダーの `index.html` をEdgeやChromeで開くだけで使用できます。
ローカルサーバーを使う場合は、Node.jsが利用できる環境で `start.cmd` を実行し、http://127.0.0.1:4174 を開きます。サーバーの終了はターミナルで Ctrl+C。

## スプリット

1. 写真を選ぶ、または編集領域にドロップします。
2. 横（列）・縦（行）の枚数をそれぞれ1〜5から選びます。最大25枚で、比率は各タイルに適用します。
3. 写真をドラッグして位置を調整します。写真上でホイールを前に回すと1%拡大、後ろに回すと1%小さくできます。読み込み時を100%として100〜3000%で調整でき、100%より小さくはなりません。回転・移動で画像のない領域はPNGでは透明、JPGでは白になります。大きさ・回転スライダーの左右の「−／＋」で1%・1度ずつ調整でき、つまみをダブルクリックすると100%・0度にリセットできます。この微調整とリセットは自由配置モードでも使えます。
4. 「プレビュー」でタイル選択画面へ切り替わります。チェックした画像を保存します。一枚ずつの保存もできます。「戻る」で編集画面へ戻ります。保存ボタンで保存設定ポップアップが開きます。

PNGは元画像から等倍で切り出します。比率を正確に保つため整数の画素数に切り詰め、端の数画素を使わない場合があります。拡大率を上げると切り出す範囲と出力画素数が減り、細部が新しく増えることはありません。ブラウザーによるデコード・色管理を経るため、元ファイルのメタデータ、ICCプロファイルは引き継ぎません。元のJPEGに存在する圧縮劣化は除去できません。

## コラージュ

1. 「自由配置」に切り替え、複数写真を追加します。
2. キャンバス比率、背景色、出力の長辺を選びます。
3. 写真をクリックまたは一覧から選択し、ドラッグで移動、スライダーで大きさ・回転・ぼかしを調整します。大きさは追加時を100%として10〜3000%。写真上のホイールは1操作で1%変更します。「写真を固定」で移動・大きさ・回転・ぼかしをロックできます。写真を右クリックすると「最前面へ移動」「前面へ移動」「最背面へ移動」「背面へ移動」を選べます。固定しても重なり順は変更できます。
4. 「プレビュー」で、選択枠・格子線のない仕上がり確認画面に切り替わります。「戻る」で編集、「保存」で保存設定ポップアップを開きます。

「配置方法」を「グリッド」にすると、横（列）・縦（行）を各1〜5で設定できます。写真は一覧順に左上から各枠を満たす大きさで配置され、はみ出した部分は枠内で切り取ります。各写真の位置・大きさ・回転も調整できます。枠数を超える写真があると保存できないため、枠を増やすか写真を削除してください。「写真を格子に並べ直す」で位置・角度をリセットします。自由配置に戻すと枠による切り取りがなくなります。

グリッド配置で写真を別の写真の枠へドラッグして放すと、枠と位置を交換します。空き枠へ放すと、その枠へ移します。大きさ・回転・ぼかしは各写真の設定を保ちます。固定された写真は交換できません。同じ枠内のドラッグは切り出し位置の調整になります。

スプリットでも背景色を選べます。回転・移動で生じた空白にその色を使い、PNG/JPGの保存にも反映します。「全てリセット」または編集写真のダブルクリックで位置を中央、大きさを100%、回転を0度に戻します。背景色は維持します。

コラージュはキャンバスの外をクリックすると写真の選択枠が消えます。設定欄の操作では選択を維持します。グリッドの中心線は各写真が入っている枠の中心で表示します。両モードのプレビューでは、画像のない領域があれば「背景色が見えている部分があります」と表示します。

## 保存設定（両モード共通）

コラージュのドラッグ中、写真の中心がキャンバスの縦・横の中心に近づくとピンクの中心線を表示します。ドラッグ終了時に消え、保存画像には含みません。写真一覧のファイル名の右にある「✕」で、その写真だけを削除できます。「写真を固定」の下の「リセット」は、フリーでは追加時の位置・大きさ、グリッドでは現在の枠の中央と枠を満たす大きさへ戻し、回転とぼかしを0にします。固定中はリセットできません。

保存設定は保存操作時だけポップアップで表示します。保存名はPCの現地時刻で `YYYYMMDD_HHmmss`（例：`20261005_083500.png`）。複数タイルは `_01` 等の連番を付けます。

- 形式はPNG/JPG。PNGは非可逆圧縮を行いません。JPGは品質95%で非可逆圧縮し、透明部分を白にします。
- サイズは100%・75%・50%・25%。縦・横それぞれに適用し、整数画素に丸めます。PNG・100%の分割出力は元画像の切り出し画素を保持します。
- 保存ポップアップには形式と保存サイズだけを表示します。一枚ならファイル保存ダイアログ、複数タイルならフォルダー選択を開きます。フォルダー内の同名ファイルは上書きせず連番にします。一枚保存で既存ファイルを選んだ場合はブラウザーの上書き確認に従います。
- Chrome/Edgeでの使用を推奨します。保存先選択に対応しないブラウザー・埋め込み画面では通常のダウンロードへ自動的に切り替えます。この場合はブラウザーの「ダウンロード前に各ファイルの保存場所を確認する」を有効にしてください。
- ネイティブ保存ダイアログの表示には利用者のクリック操作が必要です。自動テストでは保存APIを模擬し、ファイル生成・書き込み・同名保護・キャンセルを確認しています。OSのダイアログ自体は自動操作していません。

出力は指定長辺に最も近い、比率が正確な整数サイズです。写真が元画像より拡大される場合は案内を表示します。書き出しには常に元画像を使い、プレビューは使いません。最大8192pxですが、多数の大きな写真や大きな出力ではブラウザーのメモリー上限に達する場合があります。

ページを閉じる・再読み込みすると編集中の内容は消えます。ブラウザーが複数ダウンロードをブロックする場合は許可するか、各タイルを個別に保存してください。HEIC等の読み込み可否はブラウザーによります。アニメーションや複数ページ画像の編集は対象外です。

画面はウィンドウの幅・高さに追従し、全体のページスクロールを使いません。小さい画面では設定欄・タイル一覧の内部をスクロールします。現在の操作確認テストは `node verify-current.cjs` で実行できます（このPCのPlaywright・Chromeを使用）。
